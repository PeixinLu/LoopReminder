## 🎯 Usage

1. [Download the latest version](https://github.com/PeixinLu/MacOS-LoopRemider/releases) and run it

2. Click the "bell" icon in the menu bar to open settings
   
   ![](Assets/menu-icon.png)

3. Configure reminder content, frequency, appearance, animation effects, and more
   
   ![](Assets/preview-setting-basic.png)

4. Click "Start" to start the timer

## 🔧 System Requirements

- macOS 14.0+ (currently tested only on macOS 26)
- Liquid Glass effects are available only on macOS 26
- For support on additional versions, please [let me know](https://github.com/PeixinLu/MacOS-LoopRemider/issues/new)

## 📝 Development

- Built with SwiftUI.
- Basic network requests are used for update checks.
