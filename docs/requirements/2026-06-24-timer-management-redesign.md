# 计时器管理页面改版需求共识

日期：2026-06-24

## 目标

将“设置 - 计时器管理”从内联配置页改造成管理型页面：列表负责浏览、启动、暂停、展开详情；新增和编辑统一进入二级弹窗；通知停留时间改为计时器级独立配置；通知本身支持“忽略”和“完成”，为统计图和后续日志能力提供数据基础。

## 已确认规则

- `通知停留时间` 是每个计时器独立配置。
- 默认停留到下一次同计时器通知出现。间隔提醒到下一次间隔通知，定点提醒到下一个定点通知，新通知自动替换旧通知。
- 运行中的计时器不允许编辑，必须先暂停。
- 通知副标题后新增“忽略”和“完成”小按钮。完成计入完成次数；忽略、错过分别记录不同日志类型。
- 定点提醒时间选择器优先使用自定义组件，已存在时间点置灰，时间点自动排序。
- 允许删除最后一个计时器；列表为空时展示友好空状态。
- `全部启动/全部停止` 保持现有逻辑：有任一运行项时显示停止，否则显示启动。

## 设计说明

页面标题右侧承载全局操作。列表项左侧是启动/暂停按钮，中间是通知内容和提醒摘要，右侧是编辑和删除。删除按钮仅 hover 显示，右键菜单也提供删除，所有删除都需要确认。

点击列表项空白区域展开详情，不进入编辑。详情包含简要通知配置和统计图。点击“编辑”或“添加新计时器”打开二级弹窗；弹窗内集中编辑通知内容、提醒类型、通知停留时间、颜色和提示音。

统计图展示当天事件：横轴为 00:00-24:00，运行范围用浅绿色背景表示，通知触发用主题色线表示，完成事件用绿色线表示。hover 时显示灰色定位线和具体时间，靠近触发点时吸附。

## 关键交互

- 新增：点击添加 -> 打开空白草稿弹窗 -> 校验通过后保存到列表。
- 编辑：运行中禁用编辑；暂停后点击编辑 -> 修改草稿 -> 保存覆盖原计时器。
- 删除：任意删除入口 -> 确认弹窗 -> 停止对应计时器 -> 删除；删除后允许列表为空。
- 启动/暂停：有效内容才能启动；间隔提醒显示进度条，定点提醒显示下一次时间点。
- 通知处理：完成关闭通知并标记 completed；忽略关闭通知并标记 ignored；未处理自动关闭或被替换标记 missed。

- Label 区固定宽度 150-170pt，主标签使用 semibold，描述使用 secondary 小字号。
- 控件区左对齐；主控件高度保持 28-32pt；展开内容与主控件左边缘对齐。

## 时间选择器键盘输入增强

定点时间选择器打开后，popover 顶部右侧的时间预览升级为可聚焦的分段时间输入控件，并接管键盘输入。打开时从外部 `ScheduledTime` binding 读取当前时间；打开期间，鼠标网格点击和键盘输入都实时同步写回外部时间。关闭时切断输入会话，停止键盘处理和焦点抢占，再关闭 popover，避免关闭过程中重复触发或重置。

默认焦点段为小时。小时段输入单个数字时立即同步为对应小时，例如输入 `1` 即为 `01` 点；输入第二位数字后同步两位小时并切换到分钟。小时输入只校验 `00...23`，不校验不可用时间，避免已有 `12:08` 时输入 `12` 被过早判定为重复。小时段按 Tab、空格、英文冒号 `:` 或中文冒号 `：` 时切换到分钟。

分钟段输入单个数字时立即同步为对应分钟，例如输入 `8` 即为 `08` 分；输入第二位数字后同步两位分钟，并在分钟输入完成时校验不可用时间。若目标时间不可用，从目标分钟开始寻找最近的合法时间；距离相同时优先向后选择，例如 `12:08` 不可用且 `12:07`、`12:09` 都可用时选择 `12:09`。如果向后越界，则向前寻找；如果全天都不可用，则保留当前输入值。分钟段输入两位后焦点仍停留在分钟；继续输入数字时重新开始分钟输入，不自动回到小时。分钟段按 Tab、空格、英文冒号或中文冒号时切回小时。

下方小时和分钟网格接收同一份不可用时间参数：不可用分钟置灰且不能点击。鼠标点击网格只更新对应数值，不改变分段焦点，也不让顶部时间输入失去键盘焦点。回车或点击外部关闭 popover 时，先结束时间选择器会话，再关闭气泡。
