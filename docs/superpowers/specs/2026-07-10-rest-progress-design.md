# 休息中进度条设计

## 目标

循环提醒进入休息后，计时器列表与预览列表的进度条显示浅紫色休息倒计时：填充从满宽度向左缩短，文案显示“休息中”，休息结束后恢复普通绿色循环进度。

## 状态

- `ReminderController` 公开每个计时器的休息截止日期查询，并在休息开始、结束、停止、恢复和重置时发布变化。
- 视图依据计时器 ID 查询截止日期；不使用全局 `isResting` 判断，避免多个计时器同时运行时误显示。

## 呈现

- 若存在未来的休息截止日期，进度为 `remaining / restSeconds`，从 1 递减至 0；前景使用浅紫色，轨道使用更浅的紫色。
- 文案为 `休息中 · mm:ss`；没有有效截止日期时使用原有“下次通知”文案与绿色进度。
- 修改设置页 `TimerProgressFooterView` 与预览页 `TimerListItemView`，确保两处一致。

## 测试

- 休息中剩余一半时返回 0.5 进度与休息状态。
- 休息截止后返回普通循环状态。
- 普通循环进度计算保持不变。
